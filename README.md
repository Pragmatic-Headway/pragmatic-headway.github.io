# pragmatic-headway.github.io

Site da Pragmatic Headway, publicado pelo GitHub Pages em https://pragmatic-headway.github.io

- `/` — página inicial
- `/senda/` — página do Senda
- `/senda/privacidade/` — política de privacidade do Senda (link usado no Google Play)

HTML e CSS puros, sem etapa de build. A fonte Atkinson Hyperlegible está em `recursos/fontes/`, sob a licença SIL Open Font License 1.1.
